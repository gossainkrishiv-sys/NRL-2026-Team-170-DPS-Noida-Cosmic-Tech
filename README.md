# SPARKS1DPSN — Team 170

Official team website for SPARKS1DPSN (Team 170), DPS Noida. The site presents the team, member roles, and our IPRV (Indian Pothole Repair Vehicle) project for the Changemakers Innovation Challenge.

## IPRV project media

- The YouTube Shorts embed in the IPRV project section is the **IPRV robot demonstration video**: https://youtube.com/shorts/r5zNc_ZH1ko?si=MIxhHmQCrnXv4R43
- `nrl.mp4` is the additional locally hosted robot-working footage.
- `NCSC_IPRV_Project_submission.pdf` is the IPRV project details document linked from the website.

## Run locally

Open `index.html` in a browser. Keep `nrl.mp4` and `NCSC_IPRV_Project_submission.pdf` in the same folder as `index.html` so the video and PDF links work.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `team-170-sparks1dpsn`).
2. Upload `index.html`, `nrl.mp4`, `NCSC_IPRV_Project_submission.pdf`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish and open the URL shown in the Pages settings.
